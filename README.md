# CarbonIQ

CarbonIQ is an empty carbon-accounting workspace. It does not ship with activity records, facilities, emission factors, reduction projects, optimization results, or industry-specific machine-learning data.

## Run locally

1. Install dependencies with `npm install`.
2. Optionally set `GROQ_API_KEY` for AI-assisted analysis.
3. Run `npm run dev`.

Add and connect only your organization’s verified data before using analytics or reporting.
